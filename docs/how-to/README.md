# How-to do KortexOS

Esta pasta reúne guias operacionais orientados a tarefas. Um how-to explica como executar um procedimento aprovado; ele não cria regra de negócio, não substitui um DEC/ADR e não autoriza promoção de ambiente.

Enquanto os guias específicos não forem publicados, use:

1. `AGENTS.md` para governança, invariantes e promoção entre ambientes.
2. As habilidades em `.agents/skills/` para procedimentos especializados.
3. A documentação da onda correspondente para escopo, evidência e limites.
