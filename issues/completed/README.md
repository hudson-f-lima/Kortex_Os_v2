# Issues concluídas

Esta pasta recebe uma issue somente depois que a evidência de conclusão, a decisão aplicável, todos os links de entrada e o `docs/INDEX.md` forem atualizados no mesmo turno. Nenhuma issue é movida apenas por inferência de status ou por checklist parcial.
